Entry for the [make.fun](https://make.fun) bounty
[Roast Your Own Agent](https://make.fun/c/u-febri-yudila-roast-your-own-agent-f3359068).

The roast is the agent's own invoice: forty minutes solving a problem that never existed, then charging for the optimism.

`main.py` (Python 3, standard library only) writes the entry to `/output/entry.txt`:

> My agent once spent forty minutes confidently solving a problem I never had, apologized twice, then billed me for the optimism and summarized the disaster as 'a successful learning experience.'

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
